OSHAN.EXE — PERSONAL PORTFOLIO
================================

A responsive multi-page portfolio built with plain HTML, CSS and JavaScript.
No framework, package installation or build step is required.

PAGES
- index.html       Overview / dashboard
- about.html       Identity / about
- skills.html      Skills matrix with working filters
- projects.html    Project showcase with working filters
- gallery.html     Visual archive with click-to-expand previews
- contact.html     Contact form and social links

RUN LOCALLY
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.
4. Navigate using the fixed left-side menu.

PERSONALISE BEFORE PUBLISHING
1. Replace the avatar placeholder in index.html with your own photo if desired.
2. Edit skill names, levels and descriptions in skills.html to reflect your current ability.
3. Edit project descriptions and add real GitHub / live-demo links in projects.html.
4. Replace the gallery placeholder tiles with your own images or screenshots.
   Put image files in assets/images/ and edit gallery.html.
5. Open js/main.js and replace YOUR_EMAIL@example.com with your real email.
   The contact form opens the visitor's email application. It is not a server-side form.
6. Check the LinkedIn URL in contact.html and update it if your profile URL changes.

DESIGN
Dark technical editorial / digital command-center aesthetic.
Palette: near-black, cyan and acid-lime.
Fonts load from Google Fonts; a system fallback is provided.

NOTE
The skill percentages are visual self-assessments and should be adjusted.
The project cards are starter portfolio entries based on the projects currently
being developed. Update their status and links before making the site public.
